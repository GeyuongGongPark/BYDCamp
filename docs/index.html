How it works

이렇게 동작합니다

차량 터치스크린에서 앱을 켜두면 나머지는 자동으로 처리됩니다.

01
🔑

계정 설정

BYD DiLink 계정과 원격제어 PIN을 한 번만 입력하면 완료.

02
❄️

캠핑 시작

버튼 하나로 에어컨을 켜고, 28분마다 자동으로 재시작합니다.

03
🔋

배터리 감시

5분마다 배터리를 체크. 설정한 임계값 이하로 떨어지면 자동 종료.

04
😴

편하게 주무세요

배터리, 경과 시간이 화면에 실시간 표시. 알아서 관리됩니다.

Features

주요 기능

차박에 필요한 것만 담았습니다.

🔄

28분 자동 재시작

BYD 원격 에어컨은 최대 30분 동안만 동작합니다. 만료되기 전에 자동으로 다시 켭니다.

🔋

배터리 임계값 설정

배터리가 설정한 % 이하로 떨어지면 에어컨을 끄고 앱을 자동 종료합니다.

⏱

최대 시간 제한

최대 운행 시간을 설정해 배터리 방전을 이중으로 방지합니다.

🔐

세션 자동 갱신

세션이 만료되어도 자동으로 재로그인해 제어를 이어갑니다.

🌙

야간 최적화 UI

차박 환경을 고려한 다크 테마, 큰 버튼으로 야간에도 조작이 쉽습니다.

🌏

다국가 지원

KR · EU · JP · SG · AU · BR · MX · NO · IN · ID · VN 등 지역별 서버 자동 연결.

Installation

설치 방법

BYD 차량 디링크 터치스크린에 직접 사이드로딩합니다.

APK 다운로드 — Releases 페이지에서 최신 app-debug.apk를 다운로드합니다.

개발자 옵션 활성화 — 차량 설정 → 시스템 → 빌드 번호를 7번 탭합니다.

알 수 없는 앱 허용 — 개발자 옵션 → 알 수 없는 소스의 앱 설치를 허용합니다.

APK 설치 — USB 또는 파일 관리자로 APK를 차량에 복사한 후 실행합니다.

초기 설정 — 앱 실행 → 설정 → 지역·계정·VIN·PIN 입력 후 저장합니다.

⚠️

이 앱은 비공식 서드파티 앱입니다. BYD 공식 앱과 동일한 API를 사용하지만, 사용에 따른 책임은 본인에게 있습니다. 배터리 완전 방전을 방지하기 위해 반드시 종료 배터리% 설정을 확인하세요.
